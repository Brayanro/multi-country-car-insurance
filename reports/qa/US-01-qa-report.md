### Resolved environment and harness failures

- The first sandboxed `pnpm test:content` could not bind its disposable listener (`listen EPERM`). Re-running the same command with scoped loopback access passed; no persistent database was used.
- The initial Playwright default-browser launch could not find Playwright’s expected Chromium 1255 binary. The browser download was not attempted. Running the suite in the already-installed Chrome passed.
- The default-cache `pnpm build` and `pnpm --filter quote-web exec ng build --verbose` terminated with `SIGABRT` on this macOS arm64 host. The OS crash report identifies an invalid free during `lmdb@3.5.1` native N-API addon teardown under Angular build. `CI=1 pnpm --filter quote-web build` passed without source or configuration changes. This is recorded as a local default-cache/tooling limitation, not as an application defect.
- Initial QA-only test iterations had incorrect fixture assumptions (an inverted validation range and a DOB already aged 18) and browser tab-count assumptions around native segmented date input. The fixtures/assertions were corrected; current combined results above are green. No production code was changed by QA.
